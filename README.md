## Folders

The full folder map is in `AGENTS.md` (section 4.1). Added since:

- `mcp/`: the MCP server that lets an AI assistant use TalNex through the Go API (see `mcp/README.md`)
- `mcp/docs/`: the MCP server's documentation site (Next.js + Fumadocs), with the API reference
- `backend/api/`: `openapi.yaml`, the Go API's reference; a test fails if a route is missing from it
