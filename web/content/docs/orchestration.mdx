## Reading the diagram

- **One queue, two languages.** Go and Python never call each other. They only share the Postgres `jobs` table. The
  stage order is data (the `pipeline_stages` table): when a stage finishes, the database adds every stage whose
  predecessors are now all done, in the same step that saves the result. A stage with several arrows in waits for the
  last one.
- **Candidate first.** The resume is read once (`resume_read`), then the recruiter confirms what was found. A role with
  `auto_confirm` on starts the checks at once; otherwise the check waits for the confirm page. Both run the same Go
  code, `StartChecks`, which starts one project pipeline per project and the coding-profile checks once.
- **Three tracks per project.** After `precheck`, the live-site track, the repository sandbox track and the GitHub
  history track run side by side. `track_reconcile` makes the live site and the repository agree on a claim both
  tried (or the claim becomes "could not confirm"), then `feature_score` scores each feature out of 10.
- **The report.** The last project's `project_summary` starts the candidate's report. `candidate_report` waits up to
  8 minutes for the coding checks, builds the report, and `resume_cleanup` deletes the resume. Only results stay.

A project with no repository makes every sandbox stage end as "skipped", so nothing waits on it. Questions asked
later (`report_answer`, `custom_test`, `walkthrough_answer`) are single jobs the Go API adds on demand; they never
start another stage and never change a score.

## Inside `live_test`

Each claim gets a plan from the test planner, then the runner drives a real TinyFish browser one action at a time and
saves a screenshot at every step. A separate model call, which sees only the screenshots and the expected result,
checks the outcome. If a try failed, the [never-blame ladder](/docs/safety) runs before the word "broken" is used: the
page must load, it must still fail after about a minute, a second try built a different way must also fail, and a
second independent check must agree. Anything less is "could not test", which is left out of the score.
