          A Server-Sent Events stream of what TalNex is doing on one subject.
          The owner only. For an `event` it streams

          every team of the event; for a `candidate`, every project on the
          resume.


          **Order.** First `event: replay.start`, then up to 400 saved events
          (oldest first), then

          `event: replay.done`, then live events as they happen. A comment line
          `: ping` arrives every 15 seconds. A

          reconnecting viewer gets a fresh replay, so start your list again at
          `replay.start`.


          **Each event** is `event: KIND` and `data: JSON` with `v`, `at`,
          `kind`, `subject` (`kind`, `id`), `stage`,

          `claim_id`, `job_id`, `run_number` and `data`. Storage keys in `data`
          become short-lived `proof_url` or

          `proof_urls` links.


          **Kinds** (`docs/live_events.md`):


          | kind | when | data |

          |---|---|---|

          | `stage.started` | a pipeline stage starts | `try_number` |

          | `stage.finished` | a stage ends | `seconds`, `skipped`, `reason` |

          | `stage.failed` | a stage hit an error | `status` (retrying or
          failed), `error` |

          | `claims.queued` | live testing starts for a subject | `total`,
          `todo`, `claims` (id, text) |

          | `claim.started` | one claim starts | `text`, `group`, `importance`,
          `test_type`, `steps` |

          | `ladder` | each rung of the never-blame ladder | `line` |

          | `run.started` | a browser run starts | `try_number`, `test_type`,
          `steps`, `expected_result` |

          | `reason` | the agent's reason for its next move | `step`, `text`,
          `looked_at_picture` |

          | `step.record` | an action was done (screenshot taken) | `number`,
          `label`, `expected`, `observed`, `proof_url`, `box`, `url` |

          | `step.result` | a plan step ended | `step`, `steps`, `result` (done,
          failed or blocked), `observed` |

          | `run.outcome` | the run's own conclusion | `outcome`, `observed`,
          `stop_reason`, `actions` |

          | `run.finished` | the browser closed | `outcome`, `reason`,
          `actions`, `cost_usd` |

          | `check.started` | the blind proof check starts | `images` |

          | `check` | the blind proof check answered | `outcome`, `seen`,
          `images` |

          | `verdict` | a claim's final result was saved | `verdict`,
          `confidence`, `reason`, `proof_urls`, `second_check_agreed` |


          A claim is never broken before its `verdict` event. The interactive
          playground cannot show a stream: use

          `curl -N` or the MCP server's `watch_live`.
